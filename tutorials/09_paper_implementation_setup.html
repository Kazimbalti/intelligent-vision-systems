How to use this page

This page is the step-by-step companion to Lecture 7 — Reading & Implementing Research Papers and Lab 7. Do the sections in order the first time: set up Google Colab (10 minutes, nothing to install), then Google Antigravity on your laptop (30 minutes, once), then learn the reading method, and keep the reading list for the Paper Implementation Challenge.

The idea in one sentence

Read a paper in three passes (10 minutes, 1 hour, then implement it), turn every box of its main figure into a small PyTorch class, test each one before using it, and finish with a small experiment and an honest report.

1 · Google Colab, step by step

Colab is a free Jupyter notebook in your browser, running on Google's computers. PyTorch, NumPy, matplotlib, scikit-learn and OpenCV are already installed.

  1. Sign in. Open colab.research.google.com with your Google (or university Google) account.
  2. Open a lab. On the labs page click Colab next to Lab 7A. (Or in Colab: File → Open notebook → GitHub, type Kazimbalti/intelligent-vision-systems, choose LAB/Lab_7/01-pytorch-for-papers.ipynb.)
  3. Save your own copy — do this first! File → Save a copy in Drive. A new tab opens called Copy of 01-pytorch-for-papers.ipynb; work in that tab. Without this step your work is lost when you close the browser.
  4. Choose the hardware (optional). Runtime → Change runtime type → T4 GPU → Save. Lab 7 runs on the default CPU too; the GPU is only faster.
  5. Run. Click a cell and press Shift + Enter (runs it and moves to the next). Runtime → Run all runs everything. The first cell downloads lab7_checks.py; the second prints PyTorch 2.x · device: cpu (or cuda).
  6. Do the exercises. In a 🖐 Your turn cell replace the # TODO, run it, then run the ✅ check cell below it. 💡 = read the hint and try again.
  7. Keep files. Files you create live in /content and disappear when the session ends. To keep them:
from google.colab import drive
drive.mount('/content/drive')                                   # click "Connect to Google Drive"
torch.save(model.state_dict(), '/content/drive/MyDrive/unet.pt')  # survives the session

2 · Google Antigravity on your laptop, step by step

Google Antigravity is a code editor built on VS Code with an AI agent inside. You use it for real projects: several .py files, git, debugging, and code for the Raspberry Pi. (Prefer VS Code? Every step is the same; install the Python and Jupyter extensions.)

2.1 Install Python

  1. Download Python 3.11 or 3.12 from python.org/downloads.
  2. Windows: on the first screen of the installer tick "Add python.exe to PATH", then Install Now.
  3. Check: open a terminal (Windows: Start → "cmd") and type python --version. You should see Python 3.12.x.

2.2 Install Antigravity and get the labs

  1. Download the installer for your system from antigravity.google/download (Windows 10 64-bit or newer, macOS 12 or newer, or Linux) and sign in with your Google account.
  2. Get the course files: in a terminal git clone https://github.com/Kazimbalti/intelligent-vision-systems (no git? on GitHub click Code → Download ZIP and unzip).
  3. In Antigravity: File → Open Folder… → choose intelligent-vision-systems/LAB/Lab_7.

2.3 A virtual environment (once per project)

Open the terminal inside Antigravity with Ctrl + ` (the key left of 1) and type:

python -m venv .venv
.venv\Scripts\activate          # Windows  (macOS / Linux:  source .venv/bin/activate)
pip install -r requirements.txt # PyTorch, torchvision, numpy, matplotlib, scikit-learn, OpenCV, Jupyter

The prompt now starts with (.venv). PyTorch is ~200 MB; on a slow connection the CPU-only version is smaller: pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu.

Windows "running scripts is disabled" error? Run once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned in PowerShell, or use the Command Prompt terminal profile.

2.4 Run a notebook

  1. Click 01-pytorch-for-papers.ipynb. If Antigravity asks to install the Python and Jupyter extensions, accept.
  2. Top right: Select Kernel → Python Environments → .venv.
  3. Run cells with Shift + Enter, exactly as in Colab. Your files stay on your disk.

2.5 The AI agent: a tutor, not a ghost-writer

ShortcutWhat it doesUse it to
Ctrl + Lopens the Agent panel on the rightask about an equation, an error, a shape
Reviewthe agent shows the changes it proposesread them before you accept; reject anything that writes your TODOs
Boilerplateask it for plots, timing, file handlingsave time on code that is not the learning goal

The Lab 7 folder contains AGENTS.md and .agents/rules/paper-tutor.md. Antigravity loads them automatically (other coding agents read AGENTS.md too); they tell the AI to explain and give hints in this lab instead of writing the TODOs for you. Good prompts:

  • "Explain Eq. 1 of Attention Is All You Need. Give the shape of every tensor for B = 2, L = 5, d_k = 8."
  • "My U-Net output is 392 × 392 but the paper says 388. What should I check? Don't write the code."
  • "Here is my shape table for ViT-B/16. Which row is wrong?"
Course rule on AI

Use AI to understand and to review. Code you hand in must be yours and you must be able to explain every line in the viva. Every report ends with an AI-use declaration: what you asked, what you kept, what you checked yourself. Assistants invent references and numbers: always check against the PDF.

3 · The workflow: write in Antigravity, train in Colab

For the Paper Implementation Challenge, keep your model in a clean Python file and train it wherever the hardware is:

  1. In Antigravity create a folder, e.g. my-papers/se_net/ with model.py (the classes), test_model.py (shape and parameter checks) and a notebook from the Lab 7H template.
  2. Run the tests locally on CPU: python test_model.py. Fix shapes until everything passes.
  3. Push to GitHub (Tutorial 02: Git & GitHub): git add . && git commit -m "SE block + tests" && git push.
  4. In Colab (GPU runtime): !git clone https://github.com/<you>/my-papers, then import sys; sys.path.append('my-papers/se_net'); from model import SEBlock and train.
  5. Save checkpoints and results to Drive; copy the numbers into your report.

4 · How to read a research paper

Based on S. Keshav, "How to Read a Paper" (2 pages, read it). Print the paper reading worksheet and fill it as you go.

PassTimeReadOutput
110 mintitle, abstract, introduction, headings, all figures, conclusionthe 5 Cs (Category, Context, Correctness, Contributions, Clarity) and a decision: continue or not
2≈ 1 hthe method carefully (skip proofs), every figure and table, mark unknown termssummary in your words, the architecture drawn by hand, a shape table, the key equations explained
3hourseverything, including the appendix and the official codea working implementation with tests: Lab 7

The 7-step recipe from paper to code

  1. Pass 1 → paper card. 2. Pass 2 → figure, shape table, equations. 3. Map: one box = one class, one equation = one line.
  2. Build bottom-up and test every block: shape, a value you can compute by hand, parameter count, a reference implementation.
  3. Overfit one batch: loss → ≈ 0, otherwise there is a bug.
  4. Small experiment that tests the paper's main claim, with one ablation, several seeds.
  5. Report: what matched, what didn't and why; AI-use declaration.

✏️ Check yourself

  1. Which part of a paper do you need most to implement it?
    Show answer

    The method section with the architecture figure and equations, plus the training details (usually in the experiments section or appendix).

  2. The paper says "we follow [27] for the encoder". What do you do?
    Show answer

    Read paper 27 (or its official code) for the encoder details; papers build on papers.

6 · Where to find papers and code

  • arXiv cs.CV — every new computer-vision preprint, free. The ID tells the date (1505.04597 = May 2015).
  • Hugging Face Daily Papers — the day's best papers with code, models and demos. (Papers with Code now redirects to Hugging Face's trending papers.)
  • alphaXiv — comments and an AI chat on any arXiv paper: change arxiv.org to alphaxiv.org in the URL.
  • CVF Open Access — all CVPR, ICCV and WACV papers. OpenReview — ICLR and NeurIPS papers with the reviews.
  • Semantic Scholar (TL;DR summaries, citations) and Connected Papers (a map of related work).
  • Code: the official repository (link in the paper), labml.ai annotated implementations, Dive into Deep Learning, timm, niconielsen32/101-transformers (a 15-topic Transformer course with notebooks).
