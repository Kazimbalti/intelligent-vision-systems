§3.2 · definition
An attention function can be described as mapping a query and a set of key-value pairs to an output … The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key.
In plain words: like a YouTube search: your text = query, video titles = keys, videos = values. Better-matching titles get more of your attention.
#   query  : what am I looking for?      q  (B, Lq, d_k)
#   key    : what do I contain? (label)  k  (B, Lk, d_k)
#   value  : what do I give if chosen?   v  (B, Lk, d_v)
#   output = sum_j  weight_ij * v_j       out (B, Lq, d_v)
every query gets its own weighted mix of all values
§3.2.1 · Eq. (1) · Figure 2 (left)
\[ \mathrm{Attention}(Q,K,V) = \class{lk-att-soft}{\mathrm{softmax}}\!\left(\frac{\class{lk-att-qk}{QK^\top}}{\class{lk-att-scale}{\sqrt{d_k}}}\right)\class{lk-att-mix}{V} \] We compute the dot products of the query with all keys, divide each by \(\sqrt{d_k}\), and apply a softmax function to obtain the weights on the values.

Figure 2 (left), redrawn. Hover a box or a term of Eq. (1); click to pin it.

def attention(q, k, v, mask=None):
    d_k = q.size(-1)
    scores = q @ k.transpose(-2, -1)         # MatMul   Q K^T
    scores = scores / math.sqrt(d_k)         # Scale    / sqrt(d_k)
    if mask is not None:                     # Mask (opt.)
        scores = scores.masked_fill(~mask, float("-inf"))
    weights = scores.softmax(dim=-1)         # SoftMax  over the keys
    return weights @ v, weights              # MatMul   weights V
q (B, Lq, dk) @ kᵀ (B, dk, Lk) → scores (B, Lq, Lk) → @ v (B, Lk, dv) → (B, Lq, dv)
Figure 2 (left) · read bottom-up
Five boxes in the figure above = five lines of code. Always map a figure box by box.
Three details the paper leaves to you: transpose only the last two axes (tensors become 4-D later); softmax over the last axis (the keys); masked scores become −∞ before the softmax.
# check against PyTorch's own implementation

out, w = attention(q, k, v)
ref = F.scaled_dot_product_attention(q, k, v)
assert torch.allclose(out, ref, atol=1e-5)    # ✅ identical
assert torch.allclose(w.sum(-1), torch.ones(1)) # each row sums to 1

§3.2.3 · masking in the decoder
We need to prevent leftward information flow in the decoder … We implement this inside of scaled dot-product attention by masking out (setting to −∞) all values in the input of the softmax which correspond to illegal connections.
Token i may look at tokens 0 … i only: a lower-triangular mask. Because \(e^{-\infty} = 0\), blocked tokens get weight exactly 0.
def causal_mask(L):
    return torch.tril(torch.ones(L, L, dtype=torch.bool))

Derivation A · attention for word 0, step by step
  1. Scores = dot product of q0 = (1, 0) with every key: \(q_0\cdot k_0 = 1\cdot0+0\cdot1 = 0,\;\; q_0\cdot k_1 = 1,\;\; q_0\cdot k_2 = 2\) → (0, 1, 2).
  2. Scale by \(\sqrt{d_k} = \sqrt 2 \approx 1.414\): (0, 0.707, 1.414).
  3. Exponentiate: \(e^{0} = 1,\; e^{0.707} = 2.028,\; e^{1.414} = 4.113\). Sum = 7.141.
  4. Normalise (softmax): 1/7.141, 2.028/7.141, 4.113/7.141 = (0.140, 0.284, 0.576). They sum to 1.
  5. Mix the values: \(0.140\,(10, 0) + 0.284\,(0, 10) + 0.576\,(5, 5) = (1.40 + 2.88,\; 2.84 + 2.88)\).
output₀ = (4.28, 5.72): word 0 took 58 % of its information from word 2, whose key matched best.
all three words at once = matrices
\[ QK^\top = \begin{pmatrix}0&1&2\\1&0&0\\1&1&2\end{pmatrix},\quad \mathrm{softmax}\Big(\tfrac{QK^\top}{\sqrt2}\Big) = \begin{pmatrix}.140&.284&.576\\.504&.248&.248\\.248&.248&.504\end{pmatrix} \] \[ \text{output} = \begin{pmatrix}4.28&5.72\\6.28&3.72\\5.00&5.00\end{pmatrix} \]

Derivation B · the same with the causal mask
  1. Word 0 may only see word 0: scores (0, −∞, −∞) → weights (1, 0, 0) → output = v0 = (10, 0).
  2. Word 1 sees words 0 and 1: scaled scores (0.707, 0) → \(e^{0.707} = 2.028,\; e^0 = 1\) → weights (0.670, 0.330, 0).
  3. Output₁ = 0.670·(10, 0) + 0.330·(0, 10) = (6.70, 3.30). Word 2 sees everything: unchanged (5, 5).
The mask changes rows 0 and 1 only. The first row of a causal attention matrix is always (1, 0, 0, …).

Why divide by √dk? A 4-line derivation

Derivation C · footnote 4 of the paper
  1. Assume the entries \(q_i, k_i\) are independent with mean 0 and variance 1 (what initialisation gives).
  2. One product: \(\mathrm{Var}(q_i k_i) = E[q_i^2]\,E[k_i^2] = 1\cdot 1 = 1\).
  3. The dot product adds \(d_k\) independent terms: \(\mathrm{Var}(q\cdot k) = \sum_{i=1}^{d_k}\mathrm{Var}(q_i k_i) = d_k\), so its standard deviation is \(\sqrt{d_k}\).
  4. Dividing by \(\sqrt{d_k}\): \(\mathrm{Var}\big(q\cdot k/\sqrt{d_k}\big) = d_k / d_k = 1\), whatever \(d_k\) is.
Scaling keeps the scores around ±1 for every dk. Without it, at dk = 512 the scores have std ≈ 22.6.
why big scores are bad · softmax saturates
The softmax gradient is \(\dfrac{\partial s_i}{\partial z_i} = s_i(1-s_i)\).
scores zsoftmax ss(1 − s)
(1, 2, 3)(0.09, 0.24, 0.67)(0.08, 0.18, 0.22)
(10, 20, 30)(0.00, 0.00, 1.00)(0, 0, 0)
Large scores → one weight ≈ 1 → gradient ≈ 0 → attention stops learning.

Multi-head attention

§3.2.2 · Eq. for MultiHead · Figure 2 (right)
\[ \mathrm{MultiHead}(Q,K,V) = \class{lk-mha-concat}{\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)}\,\class{lk-mha-out}{W^O} \] \[ \mathrm{head}_i = \class{lk-mha-att}{\mathrm{Attention}}(\class{lk-mha-proj}{QW_i^Q,\,KW_i^K,\,VW_i^V}) \]
In this work we employ h = 8 parallel attention layers, or heads. For each of these we use \(d_k = d_v = d_{model}/h = 64\).
One big Linear computes all 8 heads at once; we then cut its 512 outputs into 8 pieces of 64.
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.h, self.d_k = n_heads, d_model // n_heads
        self.w_q = nn.Linear(d_model, d_model)   # all W_i^Q together
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)   # W^O

    def forward(self, q, k, v, mask=None):
        B, Lq, D = q.shape; Lk = k.size(1)
        q = self.w_q(q).view(B, Lq, self.h, self.d_k).transpose(1, 2)
        k = self.w_k(k).view(B, Lk, self.h, self.d_k).transpose(1, 2)
        v = self.w_v(v).view(B, Lk, self.h, self.d_k).transpose(1, 2)
        out, _ = attention(q, k, v, mask)          # (B, h, Lq, d_k)
        out = out.transpose(1, 2).reshape(B, Lq, D)  # Concat
        return self.w_o(out)
(B, L, 512) →view→ (B, L, 8, 64) →transpose→ (B, 8, L, 64) → attention → back to (B, L, 512)
Derivation D · parameters of one multi-head attention layer (dmodel = 512)
  1. One nn.Linear(512, 512) = 512 × 512 weights + 512 biases = 262 144 + 512 = 262 656.
  2. There are four of them (WQ, WK, WV, WO): 4 × 262 656.
4 · (d² + d) = 1 050 624 parameters, independent of h: 8 heads cost the same as 1.
Classic silent bug: q.view(B, h, L, d_k) directly. The shape is right, but tokens and heads get mixed. Always view(B, L, h, d_k) then transpose(1, 2), and undo both before WO. (Lab 7G, bug 4.)

Positional encoding

§3.5 · positional encoding
Since our model contains no recurrence and no convolution, in order for the model to make use of the order of the sequence, we must inject some information about the relative or absolute position of the tokens. \[ PE_{(pos,\,2i)} = \sin\!\big(pos/10000^{2i/d_{model}}\big) \] \[ PE_{(pos,\,2i+1)} = \cos\!\big(pos/10000^{2i/d_{model}}\big) \]
Attention alone sees a set: "dog bites man" = "man bites dog". Adding PE gives every position a unique fingerprint.
def positional_encoding(max_len, d_model):
    pe = torch.zeros(max_len, d_model)
    pos = torch.arange(max_len).unsqueeze(1).float()  # (L, 1)
    two_i = torch.arange(0, d_model, 2).float()       # 0, 2, 4, ...
    div = 10000 ** (two_i / d_model)                  # (d/2,)
    pe[:, 0::2] = torch.sin(pos / div)                # even dims
    pe[:, 1::2] = torch.cos(pos / div)                # odd dims
    return pe                                         # (L, d_model)

x = embedding(tokens) * math.sqrt(d_model) + pe[:L]  # §3.4 + §3.5
pos (L, 1) / div (d/2,) broadcasts to (L, d/2); pe is added to every sentence: (B, L, D) + (L, D)
Derivation E · the PE table for dmodel = 4, by hand
  1. Pairs of dimensions: 2i = 0 uses \(10000^{0/4} = 1\); 2i = 2 uses \(10000^{2/4} = 100\).
  2. pos = 0: (sin 0, cos 0, sin 0, cos 0) = (0, 1, 0, 1).
  3. pos = 1: (sin 1, cos 1, sin 0.01, cos 0.01) = (0.841, 0.540, 0.010, 1.000).
  4. pos = 2: (sin 2, cos 2, sin 0.02, cos 0.02) = (0.909, −0.416, 0.020, 1.000).
Dims 0–1 change fast (like a seconds hand), dims 2–3 slowly (like an hour hand): every position gets a different "time".
Derivation F · why sin/cos helps with relative positions (§3.5: "PEpos+k can be represented as a linear function of PEpos")
  1. Write one dimension pair as \((\sin\omega p,\ \cos\omega p)\) with \(\omega = 1/10000^{2i/d}\).
  2. Angle addition: \(\sin\omega(p+k) = \sin\omega p\cos\omega k + \cos\omega p\sin\omega k\), and \(\cos\omega(p+k) = \cos\omega p\cos\omega k - \sin\omega p\sin\omega k\).
  3. In matrix form: \(\begin{pmatrix}\sin\omega(p+k)\\ \cos\omega(p+k)\end{pmatrix} = \begin{pmatrix}\cos\omega k & \sin\omega k\\ -\sin\omega k & \cos\omega k\end{pmatrix}\begin{pmatrix}\sin\omega p\\ \cos\omega p\end{pmatrix}\).
Moving k positions = a fixed rotation that depends only on k: a linear layer can learn "look 3 words back".

Add & Norm, and the feed-forward network

§3.1 · residual + layer normalisation
We employ a residual connection around each of the two sub-layers, followed by layer normalization. That is, the output of each sub-layer is LayerNorm(x + Sublayer(x)). \[ \mathrm{LN}(x) = \gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta,\quad \mu,\sigma^2 \text{ over the } d_{model} \text{ features} \]
class LayerNorm(nn.Module):
    def __init__(self, d, eps=1e-5):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d))
        self.beta = nn.Parameter(torch.zeros(d))
        self.eps = eps
    def forward(self, x):                        # x (B, L, d)
        mu = x.mean(-1, keepdim=True)            # per token
        var = x.var(-1, keepdim=True, unbiased=False)
        return self.gamma * (x - mu) / torch.sqrt(var + self.eps) + self.beta

y = norm(x + dropout(sublayer(x)))               # "Add & Norm"
normalises the last axis (features of one token), not the batch: (B, L, d) → (B, L, d)
Derivation G · LayerNorm of one token x = (1, 2, 3, 6), γ = 1, β = 0
  1. Mean: μ = (1 + 2 + 3 + 6) / 4 = 3.
  2. Variance: ((1−3)² + (2−3)² + (3−3)² + (6−3)²) / 4 = (4 + 1 + 0 + 9) / 4 = 3.5; σ = √3.5 = 1.871.
  3. Normalise: ((1−3), (2−3), (3−3), (6−3)) / 1.871.
LN(x) = (−1.069, −0.535, 0, 1.604): mean 0, variance 1. (Divide by N, not N − 1: unbiased=False.)
§3.3 · Eq. (2) · position-wise feed-forward
\[ \mathrm{FFN}(x) = \max(0,\, xW_1 + b_1)\,W_2 + b_2 \] The dimensionality of input and output is \(d_{model} = 512\), and the inner-layer has dimensionality \(d_{ff} = 2048\).
Applied to each token separately. nn.Linear on (B, L, D) does exactly that.
class FeedForward(nn.Module):
    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        self.lin1 = nn.Linear(d_model, d_ff)    # W1, b1
        self.lin2 = nn.Linear(d_ff, d_model)    # W2, b2
        self.drop = nn.Dropout(dropout)
    def forward(self, x):
        return self.lin2(self.drop(torch.relu(self.lin1(x))))  # max(0, .)
(B, L, 512) → (B, L, 2048) → ReLU → (B, L, 512) · parameters 2·512·2048 + 2048 + 512 = 2 099 712

Encoder and decoder layers

§3.1 · Figure 1 left · encoder
Each layer has two sub-layers. The first is a multi-head self-attention mechanism, and the second is a simple, position-wise fully connected feed-forward network.
Self-attn→Add & Norm→FFN→Add & Norm
class EncoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, n_heads)
        self.ffn = FeedForward(d_model, d_ff, dropout)
        self.norm1, self.norm2 = LayerNorm(d_model), LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)
    def forward(self, x, src_mask):
        x = self.norm1(x + self.drop(self.self_attn(x, x, x, src_mask)))
        x = self.norm2(x + self.drop(self.ffn(x)))
        return x
shape never changes inside the stack: (B, Lsrc, 512) → (B, Lsrc, 512)
§3.1 · Figure 1 right · decoder
In addition to the two sub-layers in each encoder layer, the decoder inserts a third sub-layer, which performs multi-head attention over the output of the encoder stack.
Masked self-attn→Cross-attn→FFN
Cross-attention: queries from the decoder (what am I writing?), keys and values from the encoder (what did the input say?).
class DecoderLayer(nn.Module):
    # self_attn, cross_attn, ffn, norm1..3, drop  (as above)
    def forward(self, y, memory, src_mask, tgt_mask):
        y = self.norm1(y + self.drop(self.self_attn(y, y, y, tgt_mask)))

        y = self.norm2(y + self.drop(a))
        y = self.norm3(y + self.drop(self.ffn(y)))
        return y

§2 · expansive path
Every step in the expansive path consists of an upsampling of the feature map followed by a 2x2 convolution ("up-convolution") that halves the number of feature channels, a concatenation with the correspondingly cropped feature map from the contracting path, and two 3x3 convolutions, each followed by a ReLU.
def center_crop(x, size):                         # "correspondingly cropped"

The size formula: why 572 → 388, derived

Derivation I · output size of the 2015 U-Net for an input of n × n
  1. One unpadded 3 × 3 conv: n → n − 2 (conv formula with k = 3, p = 0, s = 1). Two of them: n → n − 4.
  2. Down path: \(s_1 = n-4,\; s_2 = s_1/2 - 4,\; s_3 = s_2/2-4,\; s_4 = s_3/2-4,\; s_5 = s_4/2-4\).
  3. Expand: \(s_5 = \frac{n}{16} - \frac{4}{16} - \frac{4}{8} - \frac{4}{4} - \frac{4}{2} - 4 = \frac{n}{16} - 7.75\). For n = 572: 35.75 − 7.75 = 28 ✔ (bottom of Figure 1).
  4. Up path, four times "×2 then −4": \(\text{out} = 16\,s_5 - 4(8 + 4 + 2 + 1) = 16\,s_5 - 60\).
  5. Substitute: \(\text{out} = 16\big(\tfrac{n}{16} - 7.75\big) - 60 = n - 124 - 60\).
out = n − 184. For 572: 388 ✔. Every pool needs an even size, i.e. s5 must be a whole number: valid tiles are n = 16k + 124 (… 508, 524, 540, 556, 572, 588 …).

evaluation · Dice and IoU
\[ \mathrm{Dice} = \frac{2|A\cap B|}{|A|+|B|},\qquad \mathrm{IoU} = \frac{|A\cap B|}{|A\cup B|} \] A = predicted pixels of a class, B = true pixels.
Relation: since \(|A|+|B| = |A\cup B| + |A\cap B|\), Dice \(= \frac{2\,\mathrm{IoU}}{1+\mathrm{IoU}}\).
def dice(pred, true, c):
    a, b = (pred == c), (true == c)
    total = a.sum() + b.sum()
    if total == 0:
        return torch.tensor(1.0)          # class absent in both: perfect
    return 2 * (a & b).sum().float() / total.float()

§3.1 · patches
To handle 2D images, we reshape the image \(x\in\mathbb{R}^{H\times W\times C}\) into a sequence of flattened 2D patches \(x_p\in\mathbb{R}^{N\times(P^2\cdot C)}\) … \(N = HW/P^2\) is the resulting number of patches.
def patchify(x, P):                          # x (B, C, H, W)
    B, C, H, W = x.shape
    x = x.reshape(B, C, H // P, P, W // P, P)  # split rows and columns
    x = x.permute(0, 2, 4, 3, 5, 1)            # (B, H/P, W/P, P, P, C)
    return x.reshape(B, (H // P) * (W // P), P * P * C)

class EncoderBlock(nn.Module):

class BasicBlock(nn.Module):
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(cin, cout, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(cout)
        self.conv2 = nn.Conv2d(cout, cout, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(cout)
        self.downsample = None                       # identity
        if stride != 1 or cin != cout:               # projection (§3.3)
            self.downsample = nn.Sequential(
                nn.Conv2d(cin, cout, 1, stride, bias=False), nn.BatchNorm2d(cout))
    def forward(self, x):
        identity = x if self.downsample is None else self.downsample(x)
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))              # F(x)
        return torch.relu(out + identity)            # F(x) + x, then ReLU
BasicBlock(64, 64): 2·9·64·64 + 4·64 = 73 984 parameters · ResNet-18 total 11 689 512
Derivation M · why "+ x" keeps the gradient alive (backpropagation, chain rule)
  1. Plain layer: \(y = f(x)\) → \(\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\, f'(x)\).
  2. Residual layer: \(y = F(x) + x\) → \(\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\,\big(F'(x) + 1\big)\). The "+ 1" is a gradient highway.
  3. 20 plain layers with \(f' = 0.5\): gradient × \(0.5^{20} \approx 9.5\times10^{-7}\): the first layers stop learning.
  4. 20 residual layers with a small \(F'\) (say 0): gradient × \(1^{20} = 1\): the signal reaches the first layer.
That is why the 56-layer plain net in Lab 7E reaches only 36 % test accuracy while ResNet-56 reaches 98 % (the paper's Figure 1).
