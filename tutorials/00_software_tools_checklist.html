Python Distributions (Any One)

  • Anaconda — Conda plus a large bundled package set; the least-friction choice for this course — download (or Miniconda for a minimal install)
  • Python — the plain python.org build; only if you prefer venv + pip — download

Windows environment-variable PATH: let the installer add Conda to PATH, or add these entries yourself (use anaconda3 for Anaconda, miniconda3 for Miniconda):

%USERPROFILE%\anaconda3
%USERPROFILE%\anaconda3\Library\mingw-w64\bin
%USERPROFILE%\anaconda3\Library\usr\bin
%USERPROFILE%\anaconda3\Library\bin
%USERPROFILE%\anaconda3\Scripts

Working with virtual environment

Every project gets its own isolated environment. Use whichever tool matches your Python distribution — conda is the course default.

# creates the virtual env next to the conda install
conda create -n cv python=3.12 -y
conda activate cv
conda deactivate
conda remove -n cv --all

# OR

# creates the virtual env in the current folder
conda create -p ./cv python=3.12 -y
conda activate ./cv
conda deactivate
# delete the ./cv folder to remove it

venv

The standard-library option — no Conda needed.

python -m venv myenv
myenv\Scripts\activate           # Windows (cmd)
.\myenv\Scripts\Activate.ps1     # Windows (PowerShell)
source myenv/bin/activate        # macOS / Linux
deactivate
rmdir /s /q myenv                # delete it (Windows); rm -rf myenv elsewhere

uv

The fastest option; cross-platform.

pip install uv                   # or: pipx install uv
uv venv --python 3.12 myenv
source myenv/bin/activate        # myenv\Scripts\activate on Windows
uv pip install -r requirements.txt
uv add -r requirements.txt       # add to a uv-managed project
uv sync                          # reconcile the env with the lockfile

If the uv command is not found after install, add its bin folder to PATH for the current shell — first line for Windows cmd, second for PowerShell:

set PATH=%USERPROFILE%\.local\bin;%PATH%
$env:Path = "$env:USERPROFILE\.local\bin;$env:Path"

Full setup walkthrough

Run these once, in order, on the machine you will use for the course. It assumes Windows with Git Bash; the commands are the same on macOS/Linux unless noted.

Step 1 — Install a Conda distribution

Install Miniconda (or Anaconda) from anaconda.com for your operating system. On Windows, tick the option to register Conda, or add the PATH entries above yourself. Confirm it works:

conda --version
python --version

Step 2 — Create the course environment

Create an isolated environment for the course and install its requirements. Use the exact Python version below so library versions line up with the tutorials.

conda create -n cv python=3.12 -y
conda activate cv

conda install -y ipywidgets notebook          # Jupyter support
pip install -r requirements.txt               # from the cloned course repo

Clone the repo first if you have not — see Tutorial 02 — Git and GitHub. Full environment details: Tutorial 04 — Python and Conda.

Step 3 — (Optional) GPU / CUDA check

Everything in this course runs on CPU. An NVIDIA GPU with ≥ 4 GB of dedicated memory makes the deep-learning labs several times faster; other GPUs are not supported by the CUDA build.

  • Check for a GPU: Task Manager → Performance, or run nvidia-smi in a terminal.
  • If present, install a CUDA-enabled PyTorch build into the active cv environment. Use the selector on pytorch.org to get the URL for your CUDA version:
# example: CUDA 12.4 wheels — check pytorch.org for the current tag
pip install --upgrade torch torchvision --index-url https://download.pytorch.org/whl/cu124

Verify the GPU is visible to PyTorch:

python -c "import torch; print(torch.cuda.is_available(), torch.cuda.device_count())"

True 1 means the environment is GPU-ready. False 0 is fine too — you will just run on CPU.

Step 4 — Open the project in your IDE

VS Code (course default):

  • File → Open Folder and select the cloned course repo.
  • Ctrl+Shift+P → Python: Select Interpreter and choose the cv environment.
  • Open a notebook and pick the cv kernel in the top-right.

PyCharm (alternative):

  • File → Open and select the project folder.
  • Settings → Project → Python Interpreter → Add Interpreter → Conda Environment → Use existing environment, and choose cv.

Step 5 — Handy editor shortcuts

  • Ctrl + Space — code completion (list available names and functions).
  • Ctrl + / — comment or uncomment the selected lines.
  • Go to definition — F12 in VS Code, Ctrl + B in PyCharm.
  • Parameter hints — Ctrl + Shift + Space in VS Code, Ctrl + P in PyCharm (cursor inside the parentheses).

Verify your setup

Open a terminal (Git Bash on Windows), activate the cv environment, and run:

conda activate cv

python --version          # 3.12.x
conda --version
git --version
code --version            # VS Code CLI
docker --version          # optional

python -c "import numpy, cv2, torch; print(numpy.__version__, cv2.__version__, torch.__version__)"

If every command prints a version and the last line reports NumPy, OpenCV, and PyTorch without error, you are ready.
